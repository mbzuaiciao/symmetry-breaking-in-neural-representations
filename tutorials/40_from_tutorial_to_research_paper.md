# Tutorial 40: From Tutorial to Research Paper: NeurReps Pipeline

## 1. Ten-Step Scientific Pipeline for Workshop Submissions

1. **Precise Research Question**: Formulate a single, sharp falsifiable question (e.g., "Does spontaneous symmetry breaking in representation space preserve ensemble symmetry?").
2. **Minimal Controlled System**: Build the simplest possible synthetic system (e.g. 2D 4-cluster Gaussian mixture with $\mathbb{Z}_2$ symmetry).
3. **Measurable Hypothesis**: Define mathematical order parameters $m(H)$ and distance metrics.
4. **Order Parameter Verification**: Empirically measure $m$ on positive and negative controls.
5. **Seed Replication**: Run $\ge 25$ random seeds with identical hyperparameters.
6. **Perturbation Experiment**: Introduce external field $\epsilon$ to test susceptibility.
7. **Architecture Comparison**: Compare unconstrained vs symmetry-constrained baselines.
8. **Negative Controls**: Test on random un-trained models and scrambled labels.
9. **Statistical Analysis**: Report means, standard deviations, and bootstrap confidence intervals.
10. **Scientific Interpretation**: Delineate established facts from speculative interpretations and connect to open questions.
